# Security Policy

## Supported Versions

We only support the latest version on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

**Do not** create a public GitHub issue.

Preferred method:
- Use GitHub's **Private vulnerability reporting** (recommended)
- Or email: security@yourdomain.com (replace with real contact if you have one)

We will respond within 48 hours and work with you on disclosure.

Thank you for helping keep these projects secure.
